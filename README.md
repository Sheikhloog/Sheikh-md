## ✨ Features

- QR code login
- Pairing code login
- Web-based WhatsApp connection
- Automatic session generation
- Session ID delivery through WhatsApp
- Menu and help system
- Ping, alive and runtime commands
- Owner and bot information
- Group information
- Group admins
- Tag all members
- Hide tag
- Group link
- Kick, add, promote and demote
- Image to sticker
- Optional AI API integration
- YouTube song and video downloader
- MP3 144kbps download
- MP3 256kbps download
- MP4 720p download
- Docker support
- Render deployment support
- Railway deployment support
- VPS and Termux support

# 🌐 WhatsApp Connection Website

SHEIKH-MD includes a web-based WhatsApp connection system.

You can use the following website to connect a WhatsApp number with the bot:

## 🔗 Connect WhatsApp

**Website:**

https://whatsapp-linker-3n2e.onrender.com/

### How to connect

1. Open the WhatsApp connection website.
2. Select one of the following options:

   - Get Pairing Code
   - QR Scanner

3. If you select **Get Pairing Code**:

   - Enter your WhatsApp number.
   - Include the country code.
   - Do not use `+`, spaces or dashes.

   Example:

   ```text
   923001234567
